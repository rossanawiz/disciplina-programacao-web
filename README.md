## Participar
1. Aceite o convite como colaborador.
2. Clone e crie uma branch apresentacao/seu-nome.
3. Copie alunos/template.html para alunos/seu-nome.html.
4. Personalize apenas sua cópia.
5. Faça commit, push e abra um PR para main.
6. Aguarde revisão. Após o merge, volte para main e faça pull.

A professora adicionará o link da página em alunos/index.html após integrar o PR. Essa divisão evita conflitos no índice durante a primeira colaboração.

## Estrutura
- index.html: página inicial e conteúdos.
- style.css: aparência compartilhada.
- alunos/index.html: lista das apresentações.
- alunos/template.html: modelo que cada aluno copia.
